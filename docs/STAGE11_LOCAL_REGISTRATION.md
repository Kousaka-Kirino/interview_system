# Stage 11 · 本地注册与个人空间隔离

本阶段基于 2026-10-21 用户上传的 `interview_auth_sources.zip`，添加本机注册账号功能。**不是联网注册服务，也不提供跨电脑同步。**

## 安装与兼容性

- Windows / PowerShell，项目仍在原目录，Python 虚拟环境 `.venvs/interview_system`。
- 必须已安装 Stage 8B/8C 登录保护、Stage 10D PPTX 上传功能，且原始账户数据库可以打开。
- 安装前停止 FastAPI 与 Vite。不要在注册账号或正在建立索引时运行安装器。
- 安装器会确认原始源码的 SHA-256 与提供的 ZIP 匹配；如有改动，**停止而不是覆盖**。
- 不会删除或重建原有 `aslan` 账户、登录会话、简历、答辩数据和 Chroma 文件。
- 安装时自动给原始账户 SQLite 保存一致性快照；失败时恢复源码和现有前端构建。
- 安装完成后请运行 PowerShell 启动后端与前端，重新登录。

## 使用

1. 打开 `http://127.0.0.1:5173/`，退出当前账号（如已登录）。
2. 登录界面点击 **「没有账号？在本机注册」**。
3. 用户名 3–32 位：小写英文字母、数字、下划线；不区分大小写；`aslan` 是保留账号。
4. 密码至少 12 个字符、UTF-8 编码不超过 128 字节；第二次输入确认密码。
5. 注册成功后自动登录本机新账号。可以上传自己的简历（PDF/DOCX）、补充资料（PDF/DOCX/PPTX）并进行答辩。
6. 退出登录后，可用新用户名和密码重新进入，也可使用原账号 `aslan` 登录。

**注意**：当前没有邮件验证、忘记密码找回、管理员远程管理或云账号同步功能。密码应妥善保管。软件仅限本机回环地址访问，不应直接部署为公网注册服务。

## 隔离设计

- 共享 **认证数据库**：`storage/data/interview.db`，存储账号、scrypt 密码哈希、会话与用户资料。
- 原 `aslan` 账号继续使用原始 `storage/data/interview.db` 的简历/答辩记录、`storage/uploads`、`storage/chroma`；历史资料不会迁移。
- 新账号使用 `storage/users/<账号UUID>/interview.db`、`storage/users/<账号UUID>/uploads`、`storage/users/<账号UUID>/chroma`。
- 知识标记的 `study_review.db` 继续通过 `user_id` 列隔离；历史 aslan 知识标记保持不变。
- 访问资源详情、关联简历/材料、答辩会话和搜索时，服务端依登录会话选择当前账号空间；不会信任浏览器传来的用户 ID。
- PPTX 上传继续转换为 DOCX 文字提取版，调用原有资料索引流程；图片、图表 OCR 尚不支持。
- Ollama、DeepSeek、Embedding 模型的全局连接配置仍按本机 `.env` 使用，新账号共享**模型服务**但不共享个人上传文件或向量数据库。
- 这属于**单机应用内隔离**，不是针对具有 Windows 管理员权限的恶意本地用户的操作系统级安全边界。不同 Windows 用户访问同一电脑时，请另外设置磁盘/操作系统权限。

## 回滚与备份

安装成功时输出 `[Stage 11] Backup: ...`，其目录内的 `originals` 保存原始源码，`auth_db_snapshot.sqlite3` 为安装前的认证数据库快照。请勿在创建新账户后直接用旧认证快照覆盖现有数据库，否则新注册账号会丢失。

如果安装过程中失败，安装器自动恢复它修改过的文件和前端构建；**不会删除新注册账户的数据**。需要手动回退成功安装的版本时，先停止后端和前端，再按备份目录恢复源码；请自行备份注册后新增的数据，以免与旧版本不兼容。

## 自检

在项目 `backend` 目录激活虚拟环境后运行：

```powershell
python -c "from app.main import app; print(app.openapi()['paths']['/api/auth/register'].keys())"
```

预期出现 `post`。注册失败时，请观察后端 `POST /api/auth/register` 状态码：`201` 成功、`409` 用户名重复、`422` 用户名或密码不合规、`503` 原始账号数据库结构不兼容。

**版本限制**：安装器根据用户上传的源码建立兼容清单，不适用于已在本机自行修改、但未同步到本压缩包中的登录/数据库代码。出现哈希不匹配时，请上传新的源码包重新生成，而不是强制跳过检查。
