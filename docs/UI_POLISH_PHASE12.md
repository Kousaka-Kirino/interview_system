# Stage 24B / 第十二组：整体整合、开发痕迹清理与正式手册

## 改动原则

以 Stage 24 + Stage 24A 源码为基线，只清理确定过时的展示文案、可见错误提示和开发阶段注释；**不重命名**旧模块 `stage*`、CSS 类名、认证/资源隔离字段或 URL。它们仍用于兼容旧记录和补丁识别。

## 本次修改

1. 「开始答辩」模式说明改为现有能力：PPT 翻页、逐页文字体检、自我陈述已可用，同时明确无视觉图表识别及原版式转换器限制。
2. 账号数据库故障提示不再要求用户重新安装早期 Stage 补丁；语音依赖错误提示提供可执行的依赖名称。
3. 清理 `main.py`、类型注释及组件中的过时阶段注释；不改变组件/路由行为。
4. 更新前端 README 与项目总说明的现行功能入口和限制，新增两份 Stage 24A 全量中文版手册（Markdown + PDF）。
5. 新增「静态契约及手册完整性」测试，新增本机只读验收脚本，按项检查文件、路由、PPT 翻页热修及安全要点。不会运行模型或更改数据。

## 验收边界

- 新版静态测试检查代码契约和文档，**不能代替**实际浏览器流程、登录、权限和模型功能测试。
- 原仓库 Stage 13 之前的部分旧测试未适配登录隔离，不默认将其列入全量通过声明。
- 建议运行新增后端测试、Stage 15–24A 回归、`npm.cmd run test:ui` 与 `npm.cmd run build`；并手动验证登录、两模式、PPT 翻页/降级、答题、结束复盘、专项再练及账户切换。
- 若需真实 DeepSeek 费用验证，由用户自行控制，测试脚本不会调用 API。

## 数据与安全

不修改 `.env`、API Key、SQLite、Chroma、`storage/` 或模型缓存；安装前对需要替换的源码自动备份。检测到同一位置有重叠本地修改时停止，禁止强制覆盖。正常运行与一键回滚需以本机结果为准。

## 已知未解决问题

- 语音转写依赖兼容和麦克风输入过低仍需单独修复；本组只改用户提示和手册说明。
- PPT 图表视觉理解、动画、视频播放仍不支持；无 PowerPoint / LibreOffice 仅能文字预览。
- 不承诺高并发/多进程的缓存写入协调；本地单实例优先。
- 第三方模型配置、云端费用和网络状况需根据部署机器实时验证。
