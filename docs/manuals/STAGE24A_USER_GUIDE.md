# AI 答辩训练系统 · 功能使用指南

**适用版本：Stage 24A（含 PPT 翻页修复）｜2026-10-29**

本指南面向完成安装、已在本机浏览器使用系统的同学。详细安装命令见同目录《Windows 安装与维护手册》。

## 1. 登录与账户

启动 FastAPI、Vite（本地 Ollama 方案还需启动模型服务），打开 http://127.0.0.1:5173/。没有账号就在登录页自行注册；新用户默认没有简历、知识点或答辩记录。不同账号的简历、材料、答辩和向量索引相互隔离。没有邮箱自助找回密码，妥善保存登录信息。

## 2. 数据概览

首页显示总场次、已完成场次、已回答数量、历史已评分回答均分、练习评级及最近两场有效完成答辩的场均分变化，最多显示最近 20 场走势。没有有效评分的答辩不进入分数走势；真实的零分会参与统计。评级仅供练习参考，不代表学校真实成绩。

## 3. 简历管理

进入「简历管理」，上传文字可提取的 PDF / DOCX（每份不超过 8 MiB）。可以查看原文并编辑七个中文结构化章节，以及个人基础信息；保存修正后，新建答辩将优先参考确认过的内容。`x/7` 是章节填写完整度，**不是** OCR 识别准确率；图片扫描版 PDF 可能无法提取文字。

## 4. 我的材料与 RAG

「我的材料」支持文字型 PDF / DOCX 和 PPTX（一般单文件上限 12 MiB；PPTX 最多 150 页）。上传完成后等待本地 BGE 索引成功。

- PDF / DOCX：可读原文或提取文字。
- 新版上传的 PPTX：同时保留原 PPTX 供本地展示，将可提取文字转成 DOCX 供 RAG 检索；图片里的文字不会自动 OCR。
- 旧版只保留 DOCX 文字提取版的 PPTX：可以查看文字版，但无法恢复丢失的图片及原始排版，如有需要请重新上传原文件。
- 「测试资料检索」是可选的检索检查功能，不是每次答辩必须执行的步骤。

## 5. 开始答辩：双模式

在「开始答辩」页顶部选择：

**面试模式**：至少选择一份简历，围绕个人经历、专业技能和项目经验提问；可选补充材料。

**项目答辩模式**：至少选择一份已经建立索引的 PPT / 论文 / 项目资料；不用上传真实简历也可练习。系统从材料可提取的文字出题，不会自动理解截图或图表视觉信息。

选择评委风格、初始难度、主问题数（3–30）、追问次数、答题时间；可使用 5 / 15 / 30 分钟快速预设。总时间校验是参考估计，追问和模型响应仍会额外耗时。配置信息在同一账号的本机浏览器保存；点击开始后才创建新场次并触发模型出题。

## 6. PPT 本地展示与翻页

在「我的材料」或项目答辩会话中，打开「本地 PPT 演示」。支持「上一页 / 下一页」、跳页输入（Enter 或失焦确认）、键盘 ← → / PageUp / PageDown，亦可放大查看；页面显示「当前第 X 页，共 Y 页」。

- PowerPoint 或 LibreOffice 可用时，系统尝试在本机把 PPTX 转成 PDF/PNG 并缓存图片。第一次可能稍慢；支持图片、版式展示，但不支持 PPT 动画、嵌入视频和交互切换。
- 没有转换器、转换失败或仅有旧 DOCX 时，自动退回文字预览，仍可翻页，但不是 PPT 原始视觉版式。
- 如果显示 `1 / 1`，先确认真正上传的是包含多页的 PPTX；前端不能凭空显示未被后端识别的页。旧资料需要重新上传原始 PPTX。
- **本地翻页不调用 DeepSeek，也不产生模型费用。**

## 7. 回答、语音与自我陈述

问题和唯一回答框放在答题区。可以直接打字；也可以使用麦克风录音，经本机 faster-whisper 转写后追加到同一回答框。检查文字再提交，录音转写成功并不等于答案已提交。已答题目默认折叠，难度感受可快速选择「太难 / 刚好 / 太简单」。

项目答辩模式支持 5–8 分钟「自我陈述」练习，可分段录音或手动输入文字。点击生成陈述分析才调用模型，成功后可将第一道未回答题替换为对陈述的追问。自我陈述计时独立于当前会话的每题/整场倒计时，建议预先留足时间。

**如遇麦克风录音电平过低或语音识别依赖不兼容，可直接使用文字输入继续答辩。** 不需要为了文字练习安装 Whisper。

## 8. AI 逐页体检

点击 PPT 当前页的「AI 体检本页」，模型会根据该页的可提取文字给出可能追问、薄弱点和补充建议。同一页已成功缓存的分析可以复用。不会自动理解图表图片中的数值、图形或截图；如需分析图中信息，请事先用可选择文字加以说明。

「AI 体检本页」和陈述分析是**主动触发的模型请求**，使用 DeepSeek 云端配置时可能产生费用。它们与本地翻页是两个不同操作。

## 9. 结束、复盘与知识重点

完成或提前结束后进入复盘，查看成绩、答题记录、评分和建议。原有规则复盘不依赖云端；AI 复盘会调用当前配置的模型，并可能生成示范答案、薄弱知识点、学习建议及 Markdown 导出。复习知识库可以保存与管理待巩固内容。

每账号的「自动 AI 复盘」默认关闭，开启后，后续答辩完成时会由当前网页尝试触发一次；已缓存结果优先复用。显式点击「重新生成」可能再次消耗 Token，不应假设固定价格。

## 10. 再练一次与薄弱点专项训练

复盘中可选「沿用本场资料再练一次」，进入新建答辩配置页，自动带入仍然存在的简历、材料和参数，再由用户确认开始。已删除的资料不会偷偷替换。

选择「针对薄弱点专项再练」时，后端会从当前账号上一场已缓存的 AI 复盘和真实低分题中验证薄弱点，再用于下一场提问。没有有效薄弱点或资料不一致会阻止专项再练。新场次不会改写旧答辩的评分或答案。

## 11. 数据隐私与使用限制

账号数据库、简历、演示原件、PPT 图片缓存、索引和知识库主要存于本机 `storage/`。使用 DeepSeek 云端时，出题、评价、AI 复盘、逐页体检及陈述分析会发送相应文字内容到云端，请勿上传不允许对外发送的敏感材料。项目运行日志和文件备份中不要泄露密钥或个人资料。

## 12. 常见问题

- 登录后新账号资料为空：正常，各账号独立。
- 上传扫描版 PDF 识别不到内容：需要文字型 PDF / DOCX；当前无通用 OCR。
- PPT 可翻页但图表不显示：检查是否为旧 DOCX 文字版，是否有 PowerPoint / LibreOffice。
- PPT 下一页是灰色：检查页数显示是否为 1 页；必要时重新导出 PPTX 上传。
- 语音转写失败：查看 FastAPI `Speech transcription failed` 的原始 traceback；可能是音频、PyAV、faster-whisper、麦克风音量等问题。
- 数据概览没有分数：需要已结束且含有效已评分回答的答辩。
- AI 出题/体检/复盘失败：检查本机 Ollama 或 DeepSeek 模型配置、网络、账单与后端日志。
- 浏览器访问 `/api/health` 返回 401：当前认证中间件可能保护健康检查，不单独代表服务故障。
