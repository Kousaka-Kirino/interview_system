# AI 答辩训练系统 · 前端

本目录使用 React、TypeScript 和 Vite，通过 `/api` 访问本机 FastAPI 后端。

## 开发与验证

在项目根目录以 PowerShell 进入 `frontend`：

```powershell
npm.cmd ci
npm.cmd run test:ui
npm.cmd run build
npm.cmd run dev
```

开发页面默认位于 <http://127.0.0.1:5173/>，后端默认在 `127.0.0.1:8000`；需另行启动后端。

## 页面入口

- `#dashboard`：数据概览与历史记录
- `#resumes`：简历管理
- `#materials`：我的材料（PDF / DOCX / PPTX、检索工具）
- `#configure`：创建模拟答辩
- `#session/<会话ID>`：答题会话
- `#report/<会话ID>`：答辩复盘

检索工具位于“我的材料”下方，默认折叠。用户无需手动执行检索即可开始正常答辩。

每次修改 UI 需要更新项目文档、补充相关测试，并执行 `npm.cmd run test:ui` 与 `npm.cmd run build`。本轮变更细节见 `../docs/UI_POLISH_PHASE1.md`。

## 简历解析与人工纠正（第二组）

- `#resumes`：上传后查看七个中文章节，支持编辑姓名/邮箱/电话及章节内容，点击“保存简历修正”写入当前账户的业务数据库。
- `#resumes/<简历ID>`：打开指定简历的编辑区域（仍然要求登录当前账户）。
- `#configure`：显示选中简历的章节填写完整度；缺少核心章节时可跳转“去补全”，不强制阻断练习。
- 健康度 `x/7` **仅表示章节有无内容，不是智能识别准确率**。原始提取文字和上传的文件不被手动纠正覆盖。
- 保存人工纠正后，新建答辩的提问/评分/追问会在上下文开头优先加入这些修正内容；无需新增模型调用。

API 契约和验证命令见 `../docs/UI_POLISH_PHASE2.md`。

## 第三组：原文预览（第 6、9 项）

- 「简历管理」与「我的材料」的每条记录都有「预览原文」按钮。
- PDF：在弹窗内使用浏览器 PDF 查看器；DOCX：显示即时读取原文件并抽取的纯文字，不保留 Word 版式。
- 从 PPTX 上传的材料在列表内实际显示 `_PPTX文字提取版.docx`，只能预览提取出的文字，不能还原原始 PPT 图片与排版。
- 与第二组的「查看与修正」不同，原文预览是**只读**，不覆盖用户已经修正的结构化简历数据。
- 需要正常启动 FastAPI、通过登录才能读取；关闭预览会终止未完成的请求并释放浏览器内的 PDF 临时地址。
- 新增自动化测试：`cd backend; python -m pytest -q tests/test_document_preview_group3.py` 与 `cd frontend; npm.cmd run test:ui`，另运行 `npm.cmd run build` 验证 TypeScript 和 Vite。
- 完整改动与限制参见 `docs/UI_POLISH_PHASE3.md`。

## 第四组：答辩配置优化（Stage 17）

“开始答辩”页面提供 5 / 15 / 30 分钟练习预设、题量与用时实时提示、每题/整场时间设置。
调整后的评委风格、难度、题量、追问次数和时间会按本机登录账号分别保存在浏览器 localStorage 中；不保存简历或材料的选择，切换账号会重新读取该账号独立的偏好，不会复用前一账号的配置。
时间仍限定为 0～60 整数分钟，0 为不限时。预计时长以主问题数 × 单题上限估算，追问与模型响应可能额外用时。时间不足时显示提醒，但允许用户自主决定是否进行紧凑练习；输入无效时阻止创建答辩。

创建新会话成功后，配置页把时长写入原有会话键，倒计时组件只负责现有会话的计时；历史会话的计时键不会被修改。若浏览器禁用本地存储，偏好可能无法记住，倒计时将回退至默认值（每题 2 分钟、整场不限时）。

运行 `npm.cmd run test:ui` 检查含第四组的前端回归，`npm.cmd run build` 验证完整 TypeScript 和 Vite 构建。详细说明参见 `docs/UI_POLISH_PHASE4.md`。

## 第五组：答题输入体验（Stage 18）

答题会话只保留一个可编辑回答框。可直接打字，也可以点击上方的麦克风录音；停止录音后 Whisper 转写文字会**追加**到同一个回答框，检查文字后再点击“提交回答”，无需第二次语音提交。

“这道题的难度感受”可点选 `😱 太难 / 😐 刚好 / 😎 太简单`，再次点击取消，随提交一起保存；已答题目默认折叠，点击可展开细节。提前结束会提示当前未答题的题次，取消不会结束。计时超时后先选择继续、跳过或结束；“跳过”仍使用旧后端特殊文字答案方式，可能被评分。

运行 `npm.cmd run test:ui` 检查包含第五组的所有前端测试；`npm.cmd run build` 是必须完成的完整构建检查。详细交互及已知限制参见 `docs/UI_POLISH_PHASE5.md`。

## 第六组：数据概览升级（Stage 19）

「数据概览」保留历史总场次、完成数、回答数和历史回答均分，并增加练习评级、最近两场有效答辩的场均分变化、最近最多 20 场有效已结束答辩的分数走势。评级仅供练习参考；0 分有效参与计算，未评分回答不算 0 分；只有一场或没有分数时不展示虚构环比。走势图通过当前账号的 `/api/interviews/score-history` 离线获取，无需调用 AI。

运行 `npm.cmd run test:ui` 和 `npm.cmd run build` 以验证前端；后端运行 `python -m pytest -q tests/test_dashboard_score_history_group6.py`。详细口径、API、账号隔离与安装方式见 `docs/UI_POLISH_PHASE6.md`。

## 第七组：复盘后沿用资料再练一次（第 18 项的非 AI 部分）

- 已完成的「答辩复盘」页面增加「沿用本场资料再练一次」入口。进入 `#configure/retry/<会话ID>`，先查询当前登录账号的原会话及当前简历/材料列表，再带入仍存在的简历、材料、评委风格、难度、主问题数与追问次数。
- 如原简历已删除或原会话不可访问，明确报错并阻止错误地沿用其他简历；已删除材料会被跳过并显示数量提醒，允许用户重新手动选择。
- 上一场每题和整场时间仅保存在当前浏览器。两个原会话时间值都可读取且有效时复用，否则沿用当前账号的时间偏好并提醒核对；**不复制原会话倒计时截止时间、历史回答、评分或复盘**。
- 点击复盘入口只加载普通资料接口，不会创建新会话，也不会自动运行模型。用户可以修改预填参数；明确点击「开始答辩」后才用原有 AI 提问接口创建新答辩。**本轮没有新增针对薄弱点的智能出题**。
- 安全与账号隔离继续依赖已有登录及资源归属中间件；不新建接口或修改 SQLite 表。完整说明见 `docs/UI_POLISH_PHASE7.md`。

验证：`npm.cmd run test:ui`、`npm.cmd run build`。建议使用两场已完成答辩，以及删除材料、切换账号、浏览器无历史计时设置等情况进行手动验收。

## 第八组：AI 复盘增强（Stage 21）

答辩复盘页支持可选自动生成、AI 参考答案、薄弱点自动入复习库、包含原始问答及 AI 示范的 Markdown 导出，并链接官方计费标准。自动生成开关默认关闭，按当前登录用户名隔离；只有进入有回答的已完成复盘时才可能执行一次模型调用。已缓存报告不会重复调用，主动刷新才会产生额外请求。运行 `npm.cmd run test:ui` 和 `npm.cmd run build` 验证。完整变更见 `docs/UI_POLISH_PHASE8.md`。

### Stage 22 / 第九组：自动复盘与专项训练

- 在复盘页主动开启每账号自动 AI 复盘后，后续答辩完成时会在当前会话页面尝试生成并缓存复盘；未开启时不发生自动付费调用。
- 复盘中的有效低分 AI 薄弱点可以转入专项再练，经过新建答辩页面确认后才正式开始；新场次会保留来源标记。
- 答辩结束页只保留结果统计与进入完整复盘的入口。
- 详见 `docs/UI_POLISH_PHASE9.md`；运行 `npm.cmd run test:ui` 和 `npm.cmd run build` 验收。

## Stage 23 · 双模式配置（第十组）

“开始答辩”页顶部可切换 **面试模式**（必选简历，可选材料）与 **项目答辩模式**（必选已建立索引的项目材料，不需要简历）。模式按账号保存在当前浏览器，下次进入可记住；旧记录仍按面试模式读取。答辩模式生成问题时使用资料的 RAG 文本片段，不会分析 PPT 里的图片或图表。下一阶段才开发自我陈述与 PPT 逐页分析。详细设计与测试见 `docs/UI_POLISH_PHASE10.md`。

## Stage 24：本地 PPT 演示与自我陈述

答辩模式进入会话后可在答题区上方查看已选 PPT，支持上一页、下一页、跳页和放大；我的材料页也有相同入口。新上传 PPTX 会同时保留原始文件和 DOCX 文本索引（两者在账号私有目录）；旧版仅 DOCX 上传可文字翻页。若本机没有 PowerPoint 或 LibreOffice，自动降级成文字预览。

“AI 体检本页”和“自我陈述生成追问”只有手动点击才会调用模型，并复用已保存的分析缓存；本地翻页本身不产生费用。若 Whisper 因麦克风问题无法使用，5–8 分钟自我陈述仍可手动输入/粘贴文字。

测试：`npm.cmd run test:ui`、`npm.cmd run build`。详情参阅 `docs/UI_POLISH_PHASE11.md`。
